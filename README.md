# image2cpp

Convierte imágenes en arreglos de bytes para pantallas OLED y proyectos Arduino.

Todo el procesamiento ocurre **localmente en tu navegador** — no se suben imágenes a ningún servidor.

## Demo

👉 https://rivano.click/image2cpp/

## Uso

1. Abre `index.html` en cualquier navegador moderno.
2. Carga una imagen (arrastrando o seleccionando archivo).
3. Ajusta el tamaño, umbral y orientación según necesites.
4. Copia el arreglo de bytes generado y pégalo en tu código Arduino.

## Tecnologías

- HTML5 + JavaScript puro (sin dependencias externas)
- Canvas API para procesamiento de imágenes
- GitHub Pages para hosting
